# أطلس ليبيا السياحي الرقمي 2026 - تجربة تحرير البيانات V1

هذه الحزمة تمثل أول نموذج تشغيلي قابل للرفع على GitHub Pages لمشروع أطلس ليبيا السياحي الرقمي.

## ما الذي تم تطويره؟

- خريطة تفاعلية Leaflet مرتبطة بملف GeoJSON.
- قراءة قاعدة بيانات المواقع السياحية والخدمية: `6794` نقطة.
- نموذج تحرير لكل موقع لإدخال:
  - الوصف السياحي المختصر.
  - الصور الحقيقية.
  - الاسم الإنجليزي.
  - البلدية.
  - حالة النشر.
  - درجة الثقة.
  - ملاحظات التحقق.
- حفظ التعديلات في المتصفح LocalStorage.
- تصدير:
  - GeoJSON محدث كامل.
  - ملف Patch يحتوي التعديلات فقط.
  - CSV لمراجعة الجودة.
- فرز المواقع حسب المحور وحالة النشر والنواقص.
